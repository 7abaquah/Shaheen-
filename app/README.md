# منظومة شاهين v3.4 — Shaheen Platform

تطبيق PWA واحد يدمج: تطبيق عملة شاهين (الواجهة، الوكلاء، الدخول، الدفع) + منظومة Nexus (الحوكمة، التوكنوميكس، عقد الحوسبة، المشتركون، الدفع المرن).

## الأقسام
| التبويب | المحتوى |
|---|---|
| الرئيسية | سعر SHN بالـ USDT، تقدم البيع المسبق، المعروض والحرق، ما ينتظر قرار المالك |
| الاشتراك والمستثمرون | مفتوح للجمهور دون حساب: تحديثات عامة، طلب باقة أعمال (فاتورة؛ لا بيانات بطاقات)، تسجيل اهتمام المستثمرين (ليس عرضًا ولا يقبل أموالًا) — يرسل إلى خادم الاشتراكات |
| الحوكمة | تقييم الصفقات (الهامش، Rc)، بوابة HITL، سقف الموارد اليومي 15$، سجل التدقيق |
| السوق والبيع المسبق | شراء مسبق وفق عقد EcoSystem (238 SHN/USDT، حرق 1%، إحالة 5%، 50–10,000 USDT)، دفتر أوامر بمحرك مطابقة، خطة الإدراج |
| عقد الحوسبة | عقد مكة وجدة والرياض، الطاقة النظيفة، نسبة حرق المكافأة |
| المشتركون | إضافة وتصفية المشتركين والباقات |
| الدفع | بطاقة/مدى عبر بوابة، تحويل بنكي، فاتورة مقسمة، USDT (BEP-20) مع QR حقيقي، رصيد SHN |
| المحفظة | التخزين وسحبه ومكافآته، الاستحقاق، الإيردروب، الحوكمة (تفعيل التصويت، مقترحات بقوالب، تصويت، جدولة، تنفيذ)، لوحة المشغّل (البيع، القائمة البيضاء، الإيقاف، المهلة) — معاملات فعلية |
| الوحدات التشغيلية | 10 وحدات ترفع تقاريرها للرئيس التنفيذي، محادثة وتقارير عبر Claude |
| النظام | الحساب، الصوت، عنوان الاستلام وIBAN، مواصفات SHN، سجل الأعطال B011–B023، التثبيت |

## البناء
```bash
npm ci
npm test             # اختبارات تحقق النماذج
SHN_API_BASE=https://api.نطاقك/v1 \
SHN_TURNSTILE_SITE_KEY=0x4AAAA... \
SHN_WEBSITE_URL=https://نطاقك \
SHN_APP_URL=https://app.نطاقك \
npm run build        # ينتج dist/pwa (للنشر) و dist/artifact.html
```
المتطلبات: Node.js 22+. متغيرات `SHN_*` قيم عامة (لا أسرار) تُكتب في `dist/pwa/config.js`؛ ويمكن للمالك تعديلها لاحقًا من تبويب النظام ← خادم الاشتراكات.

## تطبيق الجوال (Android و iOS)
التطبيق نفسه مغلّف بـ Capacitor 8 (المعرّف `sa.shaheen.app`). مصادر الأيقونة وشاشة البداية في `assets/` من الشعار الرسمي.
```bash
npm run build
npx cap add android && npx cap add ios      # مرة واحدة
npm run mobile:assets                       # الأيقونات وشاشات البداية
npx cap sync
npx cap open android                        # Android Studio
npx cap open ios                            # Xcode (على macOS)
```
البناء الآلي: الوسم `v*` يشغّل `.github/workflows/release.yml` في جذر المستودع فيبني:
- **Android:** APK للاختبار دائمًا، و APK + AAB موقّعين للمتجر إذا أضفت الأسرار `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
- **iOS:** فحص بناء على المحاكي دائمًا، و IPA غير موقّع؛ ومع `IOS_CERT_P12_BASE64`, `IOS_CERT_PASSWORD`, `IOS_PROFILE_BASE64`, `IOS_TEAM_ID` يُنتج IPA موقّعًا جاهزًا لـ App Store Connect (يتطلب حساب Apple Developer).

في الجوال:
- عنوان التطبيق المحلي `https://localhost` (أندرويد) و `capacitor://localhost` (iOS): أضفهما إلى `ALLOWED_ORIGINS` في الخادم، وأضف `localhost` إلى نطاقات Turnstile.
- لا توجد محفظة داخل التطبيق؛ أزرار MetaMask و Trust Wallet تفتح **رابط التطبيق العام** (`SHN_APP_URL`) داخل المحفظة لإتمام المعاملات.
- إذا تعذّر تحميل التحقق (Turnstile) داخل iOS يظهر رابط لإكمال الطلب من الموقع الرسمي.

## النشر والتثبيت على الهواتف
1. ارفع محتوى `dist/pwa` على أي استضافة HTTPS (GitHub Pages عبر الـ workflow المرفق، أو Netlify، أو Cloudflare Pages).
2. أندرويد: افتح الرابط في Chrome ← «تثبيت التطبيق».
3. آيفون/آيباد (iOS 16.4+): افتح في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

الوسم `v3.4.0` يشغّل الـ workflow ويرفق `shaheen-pwa.zip` بالإصدار.

## الشراء الفعلي على BNB Chain
**معطّل افتراضيًا** حتى اكتمال الهيكل النظامي والتراخيص. يُفعَّل بالبناء مع `SHN_PRESALE_ENABLED=1`، ويشترط عندها إقرار المشتري بالمخاطر قبل كل شراء.

تبويب «السوق والبيع المسبق» يتصل بمحفظة المستخدم (MetaMask أو Trust Wallet أو أي محفظة EIP-1193) ويشتري من عقد SHN_EcoSystem v2:
ربط المحفظة ← التبديل إلى BNB Chain ← قراءة حالة البيع والقائمة البيضاء والأرصدة ← موافقة USDT بالمبلغ نفسه فقط ← محاكاة الشراء لالتقاط سبب الرفض ← `buy(amount, referrer)` ← رابط المعاملة على BscScan.

- العناوين في `src/config.js` ← `CHAIN_DEFAULT` (تملأ بعد نشر العقود)، أو من تبويب النظام للاختبار.
- رابط الإحالة: `https://نطاقك/?ref=0x…#market`.
- التطبيق يرفض عقد v1 لأنه يصرف كميات خاطئة.
- الشراء الفعلي معطّل داخل Claude، ويعمل في النسخة المنشورة على نطاق HTTPS.
- على الجوال بدون محفظة في المتصفح تظهر أزرار فتح التطبيق داخل MetaMask أو Trust Wallet.

## الإيردروب
ابنِ القائمة من `shn-contracts`: `AIRDROP_LIST=airdrop/list.csv AIRDROP_AMOUNT=1000 npm run deploy:testnet`، ثم انسخ `deployments/<chainId>-airdrop-proofs.json` إلى `dist/pwa/airdrop-proofs.json` قبل النشر.

## ما يلزم للإنتاج (غير مضمن عمدًا)
- **المصادقة:** النسخة المستقلة وضع عرض محلي لا يحفظ كلمات المرور. اربط Supabase Auth أو Firebase Auth.
- **الوحدات الذكية:** تعمل داخل Claude مباشرة. للنسخة المنشورة انشر `ai-proxy/` (Cloudflare Worker، التعليمات في README داخله) وضع رابطه في `AI_PROXY_DEFAULT` أو في تبويب النظام.
- **الدفع بالبطاقات:** عبر بوابة مرخصة (Moyasar / HyperPay / Tap). لا تجمع أرقام البطاقات في التطبيق.
- **البيانات:** المحاكاة تُحفظ على جهاز المستخدم فقط. طلبات الاشتراك والمستثمرين تُحفظ في خادم الاشتراكات (Cloudflare Worker + D1).

src/ui.jsx      مكوّنات الواجهة
src/tabs.jsx    التبويبات
src/units.jsx   الوحدات التشغيلية
src/App.jsx     الحالة والإجراءات والتنقل وبوابة الدخول
src/join.jsx    الاشتراك والمستثمرون + إعدادات خادم الاشتراكات

assets/         مصادر أيقونة وشاشة بداية الجوال
