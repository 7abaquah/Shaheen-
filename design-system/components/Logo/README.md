الشعار الرسمي لشاهين مرسومًا من المسارات المتجهة المستخرجة من الأصل المعتمد.

- `variant`: `lockup` (الصقر والكلمة، الافتراضي)، `mark` (الصقر في الدرع)، `word` (الكلمة).
- `tone`: `gradient` (الافتراضي، على الداكن فقط)، `gold` (مسطح `gold-500`)، `black` (على الفاتح)، `white` (فوق الصور).
- `size`: الارتفاع بالبكسل. الحد الأدنى 96 للنسخة الكاملة و24 للرمز.
- `label`: النص البديل، الافتراضي «شاهين».

استخدمه بدل وضع صورة الشعار كلما كان React متاحًا. احترم المساحة الآمنة (ارتفاع مثلث المخلب) ولا تضعه داخل إطار.
