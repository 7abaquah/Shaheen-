زر بفعل واحد واضح في نصه.

- `variant`: `gold` للفعل الأساسي (مرة واحدة في الشاشة، يحمل تدرج الشعار و`glow-gold`)، `ghost` للأفعال الثانوية، `quiet` للإلغاء، `danger` للإيقاف والإزالة.
- `children`: نص الفعل بصيغة ما يحدث: «شراء SHN»، «استلام المكافآت». لا «تأكيد» أو «موافق» مجردة.
- `disabled`، `onClick`، `type`.

نص الزر الذهبي بلون `on-gold` دائمًا.
