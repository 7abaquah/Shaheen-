## التشغيل
```bash
npm ci
npm test                      # 16 اختبارًا
```

## النشر
```bash
export DEPLOYER_PRIVATE_KEY=0x...      # محفظة النشر (لا ترفعها لأي مستودع)
export OPERATOR_ADDRESS=0x...          # محفظة التشغيل اليومي (يفضل Safe متعددة التوقيع)
npm run deploy:testnet                 # BNB Chain Testnet — يستخدم MockUSDT
npm run deploy:mainnet                 # BNB Chain — يستخدم USDT الرسمي 0x55d3…7955
```
العناوين تُحفظ في `deployments/<chainId>.json`. انسخها إلى `CHAIN_DEFAULT` في `shaheen-app/src/config.js` ثم أعد بناء التطبيق، أو أدخلها من تبويب النظام للاختبار.

بعد النشر: المشغّل يستدعي `addToWhitelist([...])` ثم `setSaleActive(true)`.
